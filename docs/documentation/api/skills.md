# Skills

EmbodiedGen skills are file-based instruction bundles rather than importable
Python packages. Each skill is defined by a `SKILL.md` entry file under
`embodied_gen/skills/`.

| Skill | Entry file |
| --- | --- |
| Asset Converter | `embodied_gen/skills/asset-converter/SKILL.md` |
| Asset Creator | `embodied_gen/skills/asset-creator/SKILL.md` |
| Asset Process | `embodied_gen/skills/asset-process/SKILL.md` |
| Asset Retrieval | `embodied_gen/skills/asset-retrieval/SKILL.md` |
| Background Creator | `embodied_gen/skills/background-creator/SKILL.md` |
| Layout Creator | `embodied_gen/skills/layout-creator/SKILL.md` |
| Room Creator | `embodied_gen/skills/room-creator/SKILL.md` |
| Simulation Runner | `embodied_gen/skills/sim-runner/SKILL.md` |
| Spatial Computing | `embodied_gen/skills/spatial-computing/SKILL.md` |

Python helpers used by these skills remain documented in the corresponding
Data, Utilities, and Validators API sections.
